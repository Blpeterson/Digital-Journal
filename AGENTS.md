# Lined Notebook contributor rules

- Build goals in the hand-off in order. Do not add search, tags, sync, AI, photos, user fonts, or Linux support.
- Before a goal is done, lint, typecheck, tests, and its automated acceptance check must pass.
- Use only original, CC0, or open-license art and fonts and record sources in `packages/assets/LICENSES.md`.
- Visual values belong in schema-backed CSS theme tokens, not component literals.
- Keep OS-specific code behind an interface and record it in `GOALS.md`.
- Keep dependencies minimal and justify major additions in `GOALS.md`.
- Verify line alignment, spread layout, and cover with screenshots.
- Prefer the simplest option that preserves the notebook feel and document conflicts.
