The following font packages are bundled through Fontsource 5.3.0. Each typeface is licensed under the SIL Open Font License 1.1. A copy of each package's license is included in the installed application's `licenses/fonts` resources directory.

| App profile | Typeface | Source |
| --- | --- | --- |
| Notebook Serif | Lora | https://github.com/google/fonts/tree/main/ofl/lora |
| Friendly Sans | Nunito | https://github.com/google/fonts/tree/main/ofl/nunito |
| Clear Sans | Atkinson Hyperlegible | https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible |
| Cursive Note | Caveat | https://github.com/google/fonts/tree/main/ofl/caveat |
| Flowing Script | Dancing Script | https://github.com/google/fonts/tree/main/ofl/dancingscript |
| Curvy Script | Pacifico | https://github.com/google/fonts/tree/main/ofl/pacifico |

Sources and license status were verified on October 10, 2026. Font binaries are packaged by Vite from their corresponding `@fontsource` npm packages.
